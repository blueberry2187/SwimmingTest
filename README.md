# SwimmingTest
Is Olympic swimming becoming more competitive? And are the best swimmers pulling away or is the rest of the field catching up? This aligns with real-world contexts because it explores a broader distinction between overall improvement and relative performance. This could even be applied to other areas like education, economics, and business. 

BASIC DATA FRAMES CONTAINED:
1. df - Filtered dataframe to have swim events at the bottom of this README file
2. df_gold - Filtered for gold medals
3. df_silver - Filtered for silver medals
4. df_bronze - Filtered for gold medals
5. df_noc_agg - df aggregated by nation athletes competed for
6. df_noc_agg_gold - gold medals earned by each nation
7. df_noc_agg_silver - silver medals earned by each nation
8. df_noc_agg_bronze - bronze medals earned by each nation
